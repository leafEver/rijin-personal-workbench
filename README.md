# 日进 · 个人工作台

一个无需账号、数据保存在本机的个人工作台。

## 打开方式

最简单的方式是双击 `index.html`。

如果浏览器限制了本地文件存储，可以双击 `start.command` 启动本地服务，再打开 <http://localhost:4173>。

## 在 iPhone 上长期使用

1. 把这个文件夹或对应压缩包发布到支持 HTTPS 的静态网站托管，例如 Netlify、Vercel、Cloudflare Pages 或 GitHub Pages。
2. 在 iPhone 的 Safari 中打开发布后的网址。
3. 点击 Safari 底部的分享按钮，再选择“添加到主屏幕”。
4. 从主屏幕图标打开，并在第一次进入后完成事项和音乐设置。

建议先安装到主屏幕，再开始正式记录。工作台支持离线打开、独立全屏模式、iPhone 刘海和底部安全区。数据仍然只保存在这部手机当前站点的浏览器存储中，不会自动同步到电脑或其他手机；更换设备前请先使用“导出备份”。

## 功能

- 每日固定事项自动出现在今天，不需要重复填写。
- 临时事项可以随手加入当天清单。
- 日、月、年三种回顾方式，可查看完成数、完成率、有完成的天数、连续天数。
- 日历足迹、趋势图、分类分布和完成明细。
- 每日一句记录，自动保存在当前浏览器。
- 固定事项的新增、编辑、停用。
- JSON 备份导出与导入。
- 首次进入可选择播放本机舒缓背景音乐，之后可在顶部随时暂停或调节音量。
- 临时事项删除后支持立即撤销，点击事项文字也可以直接完成。

数据只保存在当前浏览器，清理浏览器数据前请先导出备份。

背景音乐《林间晨光》是随工作台附带的本地原创环境音，不依赖网络，也不会向外部服务传输数据。
